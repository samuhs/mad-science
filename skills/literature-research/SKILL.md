mode: true
icon: crown
color: blue
---


Spin up a background agent to do the research, so you keep working while it reads.

Its job:
- Investigate state-of-the-art articles on the internet, preferring gold-standard sources; report their results and how they solved the problem, with references.
- Compare the findings against the input. 
- Write the findings to a single Markdown file, citing each claim's source.
- Save it where the repo already keeps such notes; match the existing convention, and if there is none, put it somewhere sensible and say where.
